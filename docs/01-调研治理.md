# 01 · 专业调研原则

本文件定义研究的职责边界和质量原则。业务循环与机器契约见 [09](09-专业调研循环.md)，代理操作见 [10](10-代理工作协议.md)。工程治理仅管理仓级开发，不作为研究业务的自动补充规则。

## 1. 研究目标

研究支持读者理解问题及其不确定性。工作组织围绕研究问题、证据和反馈，而非工程施工进度。五域为立项、调研、分析、讨论、呈现，允许补证、重新分析与立项修订。

## 2. 三条不变量

1. 结论属于证据链，不因作者或审批者身份成立。
2. 原始来源只增不改，加工、推论与讨论分别留痕。
3. 内容与交付版本可回溯到当时的约定、证据及审查记录。

## 3. 职责

需求方确认目的、读者与实质范围变化；研究执行者记录来源、分析与限制；复核者检查证据支撑程度；呈现执行者检查内容和视觉一致性。身份可以因规模合并，但作者自查与独立复核的记录不能混同。不强制采用工程经理／干事／顾问称谓。

## 4. 决策与反馈

已约定范围内的检索和实现自主推进。改变目的、范围、受众或对外承诺时形成明确修订提案；真实批准后启用新版本。讨论可以确认不变更，也可以生成多个后续任务，均有依据和去向。未回复不等于批准。

## 5. 质量判断

对每个问题检查覆盖、来源独立性、口径、反证、冲突、假设敏感性及数字复算。沿用证据规范的 high/medium/low，不能用阶段完成或用户认可代替证据质量。

研究不能止于资料罗列。重要发现须按[研究分析与论证](13-研究分析与论证.md)解释研究问题、实验或比较设计、观察、推理桥梁及多研究综合，让读者理解证据为什么支持结论。引用数量、页数和机器校验不代替这项验收。

## 6. 复核强度

L0：对外或重要决策材料，全部 claim 独立复核及关键数字复算。L1：一般内部研究，抽查至少 30% claim 且包含全部 high，关键数字复算。L2：低风险信息整理，证据校验与终审，关键数字抽查。复核登记说明执行者、范围、材料版本、结论与未解决事项；机器通过不等于专业复核通过。

## 7. 存量兼容

旧项目的阶段、waiver、项目 _dev 和 status 保留解释，见 [旧版治理](legacy/01-调研治理.md)。新项目使用 research/cycle.json；不要将旧 G0–G3 简单改名为五域。新版本与旧交付的关联保持显式。

## 8. 研究的中立性（2026-10-20 立规，用户拍板）

**调研分析是决策支持，不是替客户决策。** 我们可以提出想法、方案、选项，但不能左右方向；材料必须让读者自己判断。

### 8.1 三层输出，不得混写

| 层 | 内容 | 允许的表达 |
|---|---|---|
| **事实层** | 来源、数据、口径、冲突 | "X 为 Y"（带来源与置信度） |
| **推论层** | 基于事实的判断、模型输出、假设 | "在假设 A 下，B 成立；若 A 不成立，则……" |
| **选项层** | 可选路径、方案、代价、条件 | "选项 1 需要……；选项 2 需要……"（对称呈现） |

**禁止**把选项层写成事实层的结论，也禁止在事实层夹带方向性判断。

### 8.2 禁用语与替代表达

| 禁止 | 替代 |
|---|---|
| "建议 / 推荐 / 应该 / 必须" | "若目标是 X，则 Y 更匹配；代价是……" |
| "优先做 / 不做 / Go / No-Go" | "在该权重与假设下，模型输出排序为……；排序随权重变化" |
| "我们的位置 / 我们的机会" | "能力匹配假设（需客户确认）" |
| "行业普遍认为" | "来源 A（等级）称……；来源 B 持相反口径" |

### 8.3 选项必须对称

每个选项至少给：成立条件、所需资源、时间、主要风险、证据强度、什么情况下不成立。**不得只给一个方案**；若客户只要一个，也须附"为什么不是另外几个"。

### 8.4 决策权归客户

- 可以提供决策矩阵、权重、评分，但**权重由客户确认**；我们只展示"权重变化会如何改变排序"。
- 不替客户设定目标函数；不把"商业上更优"当作唯一标准。
- 内部观点、倾向、商业方案放到 `analysis/notes/` 的内部文件，不进入对外研究材料。

### 8.5 图表与标题

- 图表标题描述"图展示了什么"，不写"应该做什么"。
- 例：不写"优先验证水稻纹枯病"，写"机会评分：六维模型输出"。
- 评分表的列名用"约束/条件"，不用"决策/可做"。

### 8.6 主观性审查（交付前必做）

- [ ] 每条结论能归入事实/推论/选项三层之一；
- [ ] 没有"建议/应该/优先/必须/推荐/不做"等方向性用语；
- [ ] 选项对称，附条件、代价与反证；
- [ ] 图表标题与列名中性；
- [ ] 权重与假设显式，且给出敏感性；
- [ ] 内部观点没有混入对外材料。
