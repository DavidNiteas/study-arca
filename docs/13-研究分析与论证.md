# 13 · 研究分析与论证

来源录入解决可追溯性；研究分析还要解释证据为何能回答问题。核心发现不能仅由标题、来源编号、证据等级、年份时间线或“有论文支持”构成。报告正文承担解释，来源清单用于核对；两者相互指向但不能相互替代。

本规范适用于机制研究，也适用于市场、政策、竞争和案例分析。证据等级与置信度仍按[03](03-证据与溯源.md)，中立性仍按[01](01-调研治理.md)；分析深度不等于替读者决策。

## 1. 从问题到回答的最小论证

重要论断给出一段读者可以复述的论证，包含以下关系。可用连贯段落、图解或表格组合，不要求机械套七个小标题。

| 环节 | 读者需要知道什么 |
|---|---|
| 研究问题与背景 | 当时尚不清楚什么？作者要区分哪几种解释？ |
| 对象与设计 | 用了什么物种、样本、药物或数据；改变了什么、比较了什么？ |
| 对照与判别 | 哪个对照排除背景、物种差异、伴随变化或替代解释？未披露的对照明确未知。 |
| 观察与结果 | 测量了什么，看到什么方向、量级、条件差异或反例？给定位符。 |
| 推理桥梁 | 为什么这个观察比替代解释更支持当前判断？它解决因果链的哪一环？ |
| 支持范围与局限 | 能得出什么，仍不能得出什么；作者结论和本调研判断分开。 |
| 综合与后续问题 | 与其他研究怎样接续、冲突或互补？还缺什么证据才能区分剩余解释？ |

量化结论保留单位、实验条件、误差或样本口径；未复算的单次论文结果标明单次引用。没有可靠数值时如实做定性解释，不制造精确数字。

## 2. 关键论文怎样读

先说明选择理由：提出了模型、提供了判别实验、加强或反驳某环节、改变了适用边界；不能只按年代或引用次数挑选。

阅读记录参考[模板](../templates/research/paper-analysis.md)。重点读取方法、结果、关键图表及作者讨论，保存到图号/表号/章节或段落的定位。区别本项目实际读到的内容与论文自称结论：

- 题录：用于历史线索，不复述尚未读到的实验和结果。
- 摘要：只复述摘要明确给出的设计与结果；剂量、重复、对照或图号没有披露即记未知，不假装看过全文。
- 正文重点：列出已读章节和图表；不自动等于逐图、补充材料和原始数据完整复核。
- 已获取但未阅读：只是材料可用，不提高阅读等级或结论置信度。

最小实验记录为“对象与干预 → 比较/对照 → 测量指标 → 观察 → 支持何种解释”。不以方法名堆砌代替理解实验为何这样设计。

## 3. 从多篇论文形成综合判断

按科学问题组织，交代后续研究具体补了前文哪处缺口。年份顺序只用于选定文献的历史重建，不冒充系统检索后的完整发现史，也不因发布时间更晚就把推论写得更强。

对每个对象至少形成一个明确综合：已解释的环节、相互独立或重复的证据、跨体系连接需要的假设、冲突的可能原因、仍可行的其他解释。不得把几个模型物种或不同药物的实验拼成同一病原内已闭合的完整因果链。

常见误读与判别：

| 观察 | 支持什么 | 仍缺什么 |
|---|---|---|
| 暴露后基因表达改变 | 通路响应或候选适应过程 | 功能扰动、回补、时间/剂量连接才能检验因果 |
| 田间突变与药敏共现 | 位点与表型关联 | 控制遗传背景的重建，排除连锁与其他差异 |
| 敲除后药敏改变，回补恢复 | 该基因参与所测表型 | 不单独证明药物直接结合该蛋白 |
| 纯化蛋白酶活被抑制 | 该条件下功能受扰 | 结合、选择性、细胞可达暴露和生理相关性 |
| 配体共晶或冷冻电镜密度 | 指定体系的结合位置/构象 | 结合到功能及病原表型的连接；残基编号不能跨物种照搬 |
| 计算对接 | 可检验的结合假设 | 实验结合与功能验证，不称作共晶 |
| 复配防效高 | 组合在该条件有效 | 同剂量单剂、期望相加模型与重复才能判断协同 |

这些是判断起点，不是用“证据还不完整”一句话替代已完成实验的解释。正向支撑与限制都要说清。

## 4. 正文、附录与PPT的分工

正文按对象或问题展开关键实验及综合判断；附录保存完整阅读卡、引文、获取状态与定位。读者无需跳到附录猜测正文的推理。市场来源同样说明统计边界为何造成差异；案例同样说明比较设计如何影响结论。

PPT的一页一个主张不等于一个分子只能一页。机制复杂时按2–3页或更多展开：结构与机制框架 → 关键论文的实验逻辑 → 多研究接续与综合判断。每页给出理解实验所需的对象、干预、比较、结果及推论，页脚保留简短作者/年份/题名定位与来源ID，备注可放完整出处。不得把正文缩成来源索引，或靠极小字号容纳全部实验。

结构高亮、过程示意、结合结构与实验图分清身份；复用或重绘时保留既有图例和证据边界。自绘实验流程标明“依据论文重建”；未经原始数据提取不得补造曲线、误差线、显著性或微观结合接触。

各格式共用分析材料和report/document.json主干，图解可简化语言但不能遗漏改变判断的对照与范围。更新完整报告时同时检查Word、HTML、PPT与发布包，不只交付专题附录。

## 5. 交付前的语义验收

抽去引文编号后逐项检查：

1. 读者能否说明作者为何做这个实验、怎样做、与谁比较、测到了什么？
2. 能否说出“因为观察X，所以在条件Y下支持Z”，而不只是“论文A证明Z”？
3. 能否区分论文作者解释、直接观察与本报告跨研究推论？
4. 下一篇研究补了哪一环；不一致是剂量、物种、分子、对照还是测量方法造成？
5. 阅读范围是否支撑所写细节，未知是否如实保留？
6. 是否保留足以判断的正向结果与主要反例，而非只有局限清单？

任一核心发现不能回答这些问题，回到分析域补读或改写，再渲染。引用齐全、页数增加、lint全绿和视觉整齐都不能单独通过研究质量验收。审查记录列出具体对象、实验定位、改写和仍未解决项，self与independent分开登记。
