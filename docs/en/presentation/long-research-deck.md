# Observed Case: Long Research Presentation

[中文](../../presentation/long-research-deck.md) | English

## Status

An observed case based on multi-round design, rendering, and review. Project-specific names, data, screenshots, and deliverables are excluded.

## Problems

- clean machine checks still hid visual collisions and weak visual centers;
- card grids obscured process, hierarchy, and evidence differences;
- slogan-like titles competed with factual claims;
- technical route, system architecture, and business flow were mixed;
- unused space coexisted with undersized primary objects;
- temporary graphics and unsupported numbers filled evidence gaps;
- later insertions made page references fragile.

## Effective patterns

1. A navigation spine: cover → contents → main sessions → sub-sessions → content → summary → close.
2. One main cognitive task per slide.
3. Relationship-first diagrams.
4. Evidence maps from known anchors to unknown space and validation exits.
5. Direct source charts and real software screenshots.
6. Alignment before containers; borders and fills are optional.
7. Enlarge the main object before adding decoration.
8. Distinct text roles for title, page claim, labels, closing statement, and navigation.

## Revision phases

| Phase | Main changes |
|---|---|
| Early structure | overflow, overlaps, legend distance |
| Visual language | canvas, type hierarchy, cover concept, technical path |
| Systemization | grid, footer, title safe area, academic wording |
| Relationship patterns | triads, loops, flows, matrices, evidence contrast |
| Navigation | sessions, sub-sessions, generated contents, release boundaries |
| Evidence | real structures, source results, software screenshots |
| Release polish | alignment, space use, frame/fill removal, page order |
| Freeze | versioned output, release directory, self-contained checks |

## Transferable conclusion

A long research deck combines narrative structure, page semantics, relationship diagrams, layout mechanics, and release control.

## Boundary

Exact dimensions, colors, type sizes, level scales, illustration content, and section counts remain project choices. Chinese and English case text is explanatory, not independent scientific validation.
