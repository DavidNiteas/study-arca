# 10 · Agent Work Protocol

[中文](../10-代理工作协议.md) | English

## Start

1. Read the current workspace model or research cycle state.
2. Identify the active agreement, round, open actions, and latest feedback.
3. Open the relevant frozen materials by ID.
4. Check the actual tools, renderer, fonts, and image-reading capability.
5. State the working assumption and begin only within the authorized scope.

## Continuation

Do not use a chat transcript as the only state. Recover state from project files and CLI output. Keep self-review, user feedback, and independent review distinct.

## Visual review

For rendered output, inspect page-level images and contact sheets. Record page and element IDs for every issue. If image inspection is unavailable, mark visual acceptance as pending.

## Handover

Record current objective, completed work, current work, blockers, decisions, material links, and the next safe action.
