# 06 · Data Source Map

[中文](../06-数据源地图.md) | English

## Routing principle

Choose sources according to the evidence needed:

- official statistics and filings for authoritative numbers;
- academic indexes for papers and methods;
- standards/database sources for structured records;
- news for events and leads, not as sole support for technical facts;
- internal records for first-person work state.

## Source discipline

Record publisher, date, scope, access method, license, and limitations. Do not treat search results as evidence until the original response is stored in a source envelope.

## Known pitfalls

Watch for duplicated syndication, stale pages, changed URLs, ambiguous units, and charts whose axis or denominator is undocumented.
