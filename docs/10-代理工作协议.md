# 10 · 代理工作协议

目标：新代理不依赖旧聊天即可找到问题、证据、讨论去向与呈现验收。先读本文，再按工作域打开相关规范；不必把所有工程治理文档装入上下文。

仓库 skill 入口：`.agents/skills/research-cycle/SKILL.md`。它只导航到本协议，不复制业务 schema。

## 开始工作的五步

1. 读 project.json、brief/brief.md，运行 `sa status <项目>`。用 `workspace_type` 判断工作区身份；research 再运行 `sa cycle status <项目>`，synthesis 读取 `work-model/model.json` 和 `synthesis/ledger.json`。未初始化循环的老项目先读旧 _dev/03，不猜测历史。
2. research 读当前 agreement、开放 round、未完成 action；synthesis 读当前工作模型、未决问题和最近一轮回执。按 ID 打开冻结材料或物化引用，不把旧发布物的结论自动用于新范围。
3. 确认本次职责：调研/分析/讨论/呈现，或 synthesis 的复盘/设计/对齐/适配输出。Synthesis 遵守 [16](16-复盘对齐与适配输出.md) 与 [17](17-研究协作角色.md)：首席研究员拥有目标和最终决定；主代理按情景切换研究助理与助理研究员身份。研究助理不得擅自扩大调研，助理研究员可以提出设计和方案但不能代替首席研究员接受。允许首席研究员先自然口述，代理先复述再问高影响问题，不把缺口清单变成审问。
4. 检查实际工具：检索源是否可访问；呈现任务能否渲染，以及模型是否真的能读取预览。能力目录宣称支持不等于实测成功。
5. 执行最小下一步：research 按 09 追加记录；synthesis 按 16 通过 `synthesis apply` 追加复盘、问题、回答、修正和对齐记录，关闭轮次后用 `synthesis snapshot` 冻结，正式呈现使用 `build --snapshot`。需要多视角调研时可按 17 组织研究顾问委员会；边界明确的一站式工作可派研究专员。两类工作区都通过 `work-orders/` 维护本地工单。结束时报告已完成、未决和下一步，不把后续代理需要的信息只留在聊天。

## 各域操作

- 调研：从问题和缺口出发，按 06/08 选源，按 03 入库；检索、摘录、定位符与口径可复核。
- 分析：对证据作反证与口径检查；结论先进入 findings 台账；回答不足时写清限制，不填补猜测。
- 关键研究解释：按[13](13-研究分析与论证.md)检查问题、设计/对照、观察、推理桥梁和综合；抽去来源编号后仍能说明实验为何支持判断，才进入呈现。
- 讨论：引用材料版本；逐条登记 feedback 和 disposition。需后续工作的创建 action；无变更写 rationale。
- 立项修订：新 agreement 说明 supersedes/change_reason；首席研究员实际批准后才使用 approved。未批准草案可以保留，不启动其正式轮次。
- 呈现：读 [11](11-PPT设计方法与模式.md) 或使用仓库 presentation-design 技能；内容冻结 → 设计意图 → 布局 → 目标软件渲染 → 读取图片 → 按元素 ID 修订 → 重渲染 → 再读图。引用输出哈希对应的最终预览，不能复用上一版审查。

## 视觉检查清单

- 信息主次、阅读顺序、标签与图形关系是否清楚；
- 对比度、文字密度、裁切、遮挡、乱码、默认主题效果是否合适；
- 线条是否指向正确对象，空间位置是否暗示了无依据的关系；
- 图形、结构、数字与材料一致；来源、口径、覆盖边界可找到；
- 机器测量与看图分别记录，审查者标明 self 或 independent。

读图失败：登记 pending，说明失败点，完成其余可做工作；不能把导出成功写成“看过”。

## 可运行案例

- 最小记录示例：`templates/research/records.example.json`（先冻结批准凭据，再按真实任务填写；示例不是首席研究员批准）。
- 示例研究轮次：`<program>/nodes/p-20261020-ag-fungicide/research/cycle.json`，只读查看/接手，以 CLI 当前输出为准。
- 自由画布与布局实验的方法边界见 [11](11-PPT设计方法与模式.md) 和 [12](12-系统定位与能力管理.md)。项目级实现与实验记录随具体研究项目保存，不属于产品公共入口。

## 交接最小内容

当前约定 ID、轮次 ID、未完成任务 ID、最新回答及限制、冻结材料入口、工具能力缺口。用这些 ID 指向唯一记录，不另抄一份详细状态。

## 新代理验收题

在现有材料范围内，读取杀菌剂轮次、指出覆盖边界，完成一条经授权的后续任务；如任务含呈现，实际读取最终预览并记录审查。另一实例完成且记录可复核，才通过独立接手验收；主代理自演练只算预检。
