# 05 · 报告规范

中文 | [English](en/05-reporting.md)

> 报告是调研的**主干交付物**。它的第一职责不是好看，而是**让读者能验证每一句话**。

读者还要能理解论断怎样从证据推出。关键研究按[13 · 研究分析与论证](13-研究分析与论证.md)交代问题、实验/比较设计、观察、推理桥梁及综合判断；正文不能只有来源索引，附录阅读卡不能替代正文解释。

## 1. 结构

```text
标题 / 副标题 / 日期 / as-of / 密级 / 版本
摘要（≤ 500 字，结论 + 置信度 + 关键数字）
1. 研究问题与方法
   1.1 问题与范围（含不做什么）
   1.2 方法与来源（数据源、检索策略、证据分级）
   1.3 局限（写在前面的诚实）
2. 背景与现状
3. 发现（按子问题分章，每章 3–6 条结论）
4. 分歧与不确定性
5. 结论、推论与对称选项（条件与限制明确）
6. 附录
   A. 来源清单（id / 标题 / 发布方 / 日期 / 等级 / 链接）
   B. 基准事实表
   C. 冲突登记
   D. 检索日志摘要
变更记录
```

## 2. 引用格式

- 行内引用用脚注式标记：`2025 年产量同比增长 12.3%[^s-0001]。`
- 一条论断多个来源：`[^s-0001][^s-0009]`。
- 附录 A 自动生成脚注定义，**格式固定**：

```text
[^s-0001]: 国家统计局，《2025 年国民经济和社会发展统计公报》，2026-01-20，E1，https://...
```

- 禁止裸链接、禁止"资料来源：网络"、禁止引用自己（`analysis/notes` 不是证据）。

## 3. 置信度的措辞映射

| 置信度 | 报告措辞 | 附加要求 |
|---|---|---|
| high | "为 / 达到 / 增长 X%" | 可直接陈述，附来源 |
| medium | "据……，约为 / 估计" | 必须点出发布方 |
| low | "有迹象表明 / 单一来源显示" | 必须说明证据薄弱的原因 |

**禁止**："业内普遍认为""据了解""相关人士称"——除非有具名来源且入库。

## 4. 事实、推论与选项分离

- **事实段**只写能被证据支持的内容，不夹带判断。
- **推论段**写依据、假设及失效条件；**选项段**对称给出条件、资源、时间、风险、证据与反证。
- 推论与选项不得超出 `scope`（例如样本只覆盖一线城市，不能推全国）。

## 5. 数字规范

- 单位、口径、期间三者必须同时出现，或指向 `facts.json` 的 fact id。
- 同比/环比、名义/实际、累计/当期，写清楚。
- 百分比变化写清基数："增长 12.3%" vs "增长 12.3 个百分点"。
- 推算值标 `（推算）` 并写假设。

## 6. 长度与可读性

- 摘要 ≤ 500 字；每章开头 2–3 句"本章结论"。
- 一个自然段一个意思；结论先行。
- 表格优于长段落罗列数字；图必须有标题、单位、来源。
- 术语首次出现给定义；缩写建表。

## 7. 版本与变更

- 版本号 `v<major>.<minor>`：结论变化 → major；补证、措辞、排版 → minor。
- 每次出稿在"变更记录"写：版本、日期、改了什么、为什么（对应 claim/fact 变更）。
- 旧版本不删除，新版本另起目录。

## 8. 机器可检查项

`sa lint --report <file>` 当前实现：

- 报告中每个 `[^s-*]` 引用的来源存在；引用未被任何 claim/fact/conflict 使用时告警；
- 报告中每个 `[^c-*]` 引用的 claim 存在且为 active；
- 报告中每个 `[^f-*]` / `[^x-*]` 引用存在；
- 没有任何引用时给出警告；
- 高置信度 claim 未在报告中直接引用时给 info（背景结论可忽略）。

尚未自动检查（属复核清单，人工执行）：stale 引用、摘要字数、附录与台账一致性、版本号与目录一致性。

## 9. 中立性审查

按 `01-调研治理.md` §8 执行。交付前逐项检查：

- [ ] 事实、推论、选项三层分开，没有混写；
- [ ] 没有"建议/推荐/应该/必须/优先做/不做/Go/No-Go"等方向性用语；
- [ ] 选项对称：条件、资源、时间、风险、证据、反证齐全；
- [ ] 权重与假设显式，附敏感性；
- [ ] 图表标题与列名中性（描述"展示了什么"，不写"该做什么"）；
- [ ] 内部倾向与商业方案未进入对外材料。

**判定**：只要出现一个"替客户拍板"的句子，即视为未通过中立性审查，退回改写。
