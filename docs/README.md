## 与工程治理内核的关系

- `engineering-governance` 管理仓级开发工单；不作为专业调研业务的默认补充规则。
- 调研业务按“立项—调研—分析—讨论—呈现”及反馈循环独立定义，契约见 [09](09-专业调研循环.md)。内部开发工单保留在开发仓，不属于产品文档。

## 规范的性质

- 规范是**可执行的**：每条硬约束都应能被 `sa lint`、检查单或阶段门检查到；写了却无法检查的条款，视为建议而非规范。
- 规范是**活的**：调研中发现的失效条款当场修正，并在开发仓的对应产品或开发工单留痕。
