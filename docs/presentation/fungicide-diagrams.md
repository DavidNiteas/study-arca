# 已观察案例：杀菌剂从格子到图解

日期：2026-10-27。来源为农用杀菌剂项目演示 v7.1 → v7.2，发行 v2.2；原始输出与审查由项目 r-mvp-005 / p-mvp-005 保存。此处只提炼设计经验，不复制业务数据、图片或交付物；读者无需持有该项目即可理解方法。

## 用户问题与设计变化

用户指出大量格子化、模式化呈现，希望保留必要表格，同时像首页一样自行绘图。最终 30 页中 13 页改成原创图解；用户回复“很不错”，随后要求把设计知识沉淀入框架。该反馈是设计接受度观察，不是科学事实验证。

| 原设计 | 新设计 | 为什么有效 / 什么时候不照搬 |
|---|---|---|
| 三栏研究导读卡片 | 从应用到分子再到试验证据的阅读路径 | 表达观察层次；若任务是独立查阅菜单，不必画成过程 |
| 连续 FRAC 表格 | 按作用过程划分支线，代码、类别、代表对象就近标注 | 分类关系可见；保留代码以便查阅，位置不表达化学相似性 |
| 分子旁两段正文 | 完整分子 + 呼吸链作用位置示意，同类页突出不同位点 | 把“作用于哪里”变成可见关系；不是真实蛋白比例或结合模型 |
| 三个协同案例卡片 | 田间观察与室内试验分区，配简图、指标与对照缺口 | 防止将防效与协同混为一谈；不把不同对象的数字做排名 |
| 两栏组合说明 | 成分节点与配比标注，汇合到试验条件和指标 | 明确组合组成；圆面积没有编码效力，也不证明相互作用 |
| 三个研究路径卡片 | 同一起点分出对称路径，各附投入、回答和局限 | 展示选择对应的问题；颜色和顺序不承担优先级 |

## 看图带来的具体修正

第一轮文字边界检查为零溢出，但实际图片显示：CYP51 页小标题与说明挤在一起，细胞壁标签压在线条上。移动说明、缩短纤维线条后再渲染。这说明“不越框”与“不遮挡、易理解”不是同一项检查。

第二轮出现轻微文字宽度越界，改成明确分行；同时审查发现抑制符号可能让人误读成“酶抑制合成”。最终将抑制符号指向酶，用另一条线将酶连到其催化过程。视觉评审需要核对图形语义，不能只评颜色和整齐程度。

共经历三轮 PowerPoint 实际渲染；最终读取五张联系表覆盖全部 30 页，并放大复看关键修订页。最终机器文字检查为零溢出。自查记录与哈希在项目冻结快照中；本次没有独立实例复核，也未验证其他软件渲染一致性。

## 可迁移结论与边界

- 按内容关系选形式，整体会自然产生节奏；不能把“13/30 页重绘”变成任何演示的图解比例规定。
- 一致的机制图可帮助跨页比较；反模式是无视内容的重复，不是重复本身。
- 科学图与关系图使用可编辑路径和文字，便于按反馈局部修正；三维科学素材仍可使用可信图片，不要求全篇矢量化。
- 本例足以作为有边界的教学案例；尚未证明此方法对所有受众、主题和模型同样有效。新代理在其他主题的实际表现应另记案例。
