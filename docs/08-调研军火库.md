# 08 · 调研军火库（MCP 信息源目录）

中文 | [English](en/08-research-toolbox.md)

> 仓级资产：调研可接入的**搜索/抓取类 MCP 服务器**目录。立项选源时先查本表，不重复踩点。
> 与 `06-数据源地图.md` 互补：06 管内置 25 个结构化数据源，本表管外部 MCP。
> 收录日期：2026-10-20。定价/额度大多**未验证**，接入前以官方页面为准。
>
> **合规分级**：🟢 官方 API / 自托管，低风险 · 🟡 爬虫类，违反平台 ToS，稳定性与账号风险自负 · 🔴 逆向私有接口/需登录态，高风险，对外项目慎用。

## 9. 维护纪律

1. 新装一个 MCP，先在本表补条目（功能/来源/特性/key/合规分级），再进 `06` 路由表。
2. 每次使用后在条目"活跃度"旁标注实际体验（稳定性、中文质量），让军火库带使用痕迹。
3. 爬虫类（🟡/🔴）仅用于内部线索搜集，**不作为对外报告的来源信封**；对外引用须回溯到原始发布方。
4. 定价/额度以官方为准；表中数字均为 2026-10 调研时点的未验证值。
