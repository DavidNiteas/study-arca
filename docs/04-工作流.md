# 04 · 专业调研工作流

中文 | [English](en/04-workflow.md)

五域循环的业务契约见 [09](09-专业调研循环.md)，操作入口见 [10](10-代理工作协议.md)。旧项目 G0–G3 的操作说明保留在 [legacy/04](legacy/04-工作流.md)。

## 1. 立项

保留需求原话，明确目的、读者、问题、范围、截至日期与验收口径。形成 agreement，批准凭据冻结后才建立正式 round。没有批准的范围变化以 draft 保存。

## 2. 调研

围绕问题建覆盖表，优先原始及结构化来源，记录检索路径和缺口。使用 sa source 入库；反例和矛盾同样保留。补证任务引用产生它的讨论，明确关闭依据。

## 3. 分析

检查来源独立性、时间和统计口径，实施反证与复算，维护 claims/facts/conflicts；回答可为 answered、partial、insufficient。限制与未决冲突不能从输出消失。

## 4. 讨论与回流

讨论绑定具体材料版本，明确反馈来源及处理依据。去向可以是补证、再分析、立项修订或呈现；不变更则解释理由。实质范围变化回到需求方确认，原有交付继续绑定旧约定。每个任务完成或暂搁后记录 outcome，再形成最新 answer。

## 5. 呈现

选取经过检查的内容，冻结内容 LR；编制布局 LR，调用目标软件渲染并实际读取图片，按对象 ID 修订再复看。内容问题回到分析或讨论，视觉问题在呈现域闭环。记录内容、布局、成品、预览、渲染器与审查身份。

## 6. 一轮结束与交接

问题有最新回答、任务有结果、讨论有去向、未决事项有记录后关闭轮次。关闭不等于发布、不等于全部问题已证实。交接提供当前约定与轮次 ID、开放任务、材料入口和能力限制。重要交付仍需相应独立复核。
