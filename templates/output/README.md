# Output 模板

- `request.json`：输出请求；
- `document-plan.json`：DOCX 内容计划；
- `experience-plan.json`：HTML 交互报告计划；
- `deck-plan.json`：PPT 页面计划；
- `render-layout.json`：渲染布局；
- `output-record.json`：输出登记记录；
- `review-record.json`：输出审查记录。

把模板复制到项目工作目录，替换占位符，并通过 `cycle capture` 冻结后再登记到 `outputs/registry.json`。
